# Electric Car Sales Predictor

This repository contains a Streamlit-based web application and training scripts used to analyze historical electric vehicle (EV) sales data and forecast future sales using SARIMA time-series models. The focus is on Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs). 

---

## 📁 Project Structure

```
app.py                       # Streamlit application
train.py                     # Script to prepare data and train SARIMA models
IEA-EV-dataEV salesHistoricalCars.csv  # Historical EV sales dataset (IEA format)
ev_model_bev.joblib          # Pre-trained BEV SARIMA model (generated by train.py)
ev_model_phev.joblib         # Pre-trained PHEV SARIMA model (generated by train.py)
ev_sales_model.joblib        # (Possibly unused or alternative model)
requirements.txt             # Python dependencies
runtime.txt                  # Runtime configuration for deployment (e.g., Heroku)
```

> ✅ **Note:** The dataset file must be located in the root directory when running either the training script or the Streamlit app.

---

## 🛠️ Setup & Installation

1. **Create a Python environment** (e.g. `venv`, `conda`):
   ```bash
   python -m venv .venv
   # or: conda create -n evsales python=3.11
   # activate environment after creation
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **(Optional) Train models**
   If you want to retrain the SARIMA models or the model files are missing:
   ```bash
   python train.py
   ```
   The script will read the CSV, preprocess the data, and output `ev_model_bev.joblib` and `ev_model_phev.joblib`.

---

## 🚀 Running the Application

Start the Streamlit app to explore historical sales and view forecasts:

```bash
streamlit run app.py
```

Once launched, open your browser at the URL shown (usually `http://localhost:8501`).

### 🔍 Features
- **Historical analysis**: Filter EV sales by year range and region.
- **Forecasting**: SARIMA models predict monthly sales through 2040 for BEVs and PHEVs.
- **Interactive plots** using Plotly and Pandas.

---

## 🧠 How It Works

1. **Data loading**: `app.py` loads the CSV and filters for relevant EV sales data (cars, vehicles, BEV/PHEV).
2. **Model inference**: Pre-trained SARIMA models (loaded via `joblib`) generate future sales forecasts.
3. **Training pipeline**: `train.py` processes data into monthly time-series and fits SARIMA(1,1,1)x(1,1,1,12) models.

> ⚠️ If datasets or model files are missing, the app will display error messages and stop execution.

